# Crédits des illustrations anatomiques

Ces dix SVG sont des rendus statiques générés avec [Anatome](https://github.com/Rippy1911/anatome), à partir de données anatomiques ouvertes. Les groupes musculaires ciblés sont recolorés en rouge pour les icônes de GYM NOTES.

Les tracés anatomiques proviennent de `react-native-body-highlighter` par ELABBASSI Hicham, © 2022, sous licence MIT. Le texte complet de cette licence est dans [`LICENSE-MIT`](./LICENSE-MIT).

Les images sont enregistrées dans l’application. Elles ne contactent pas l’API Anatome à l’utilisation et peuvent être mises en cache pour le mode hors ligne.
